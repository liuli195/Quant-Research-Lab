# 迁移候选的设计边界与调查证据

本文件记录候选的事实来源和待决项，不替代正式规格，不是配置最终写入摘要。路径均相对仓库根目录；证据基于固定基线 `bd07f9ce5f13d18d0a17831759721d91647a727b`。

## 已收敛的概念

- **普通受保护检查**：只做内存行为及必要静态读取，并由新工具实际记录保护证据的检查。不是“名字含 unit 的旧组”，也不是“数据库连接字符串写了内存”。
- **聚焦真实检查**：必须运行不可替代外部环境边界、明确登记为未保护的检查。真实角色不是自动执行许可，不等于所有旧集成测试都必须保留。
- **真实核心主路**：从已有公开入口贯穿业务链路、验证结果与必要恢复行为的最小测试。不等于以多个不连贯单元断言拼接的成功。
- **条件等价复算**：依赖指定私有行情快照的三个历史场景复算。缺少快照时跳过，只能证明其余结构与摘要链检查仍在，不能证明复算等价。
- **JIT 公式检查**：当前独立 JIT 检查实际验证的风险缩放公式；不代表即时编译验收。生产 JIT 能力与现行正式编译契约是另外两件事。

这些是本迁移的操作边界，不增设独立领域层或词汇表体系，也不为可逆配置决定创建架构决策记录。

## 设计树与边界场景

1. 目标是可信且低成本的统一验证，不是开发新的测试平台。
   - 复用既有工具、公开入口、夹具和领域模块；没有真实构建就保持空。
   - 中间方案若依赖整组未知豁免，不能作为迁移成功。
2. 能在内存验证的行为优先内存化。
   - 只有解析 JSON 的测试不应先造文件；需验证原子固化的测试仍真实写盘。
   - 普通逻辑不应因包初始化提前载入数据库而失去保护资格；在真正使用数据库的已有边界才载入。
3. 原生边界按实际能力区分。
   - DuckDB `:memory:` 仍是真实原生数据库，不能进入当前工具保证的普通组。
   - SQLite `:memory:` 与文件型付费预览库不是同一种测试边界；一次性消费必须真实验证。
4. 真实覆盖要小但完整。
   - Python 数据/文件/进程、Chromium/Windows 会话、Git/PowerShell/共享虚拟环境是三类环境，不固定为三个巨型检查。
   - 已授权的重复独立 JIT 去重无需重问，公式仍保留。其他低收益或极端物理用例若实质减少唯一覆盖或能力，须先说明原因、收益、成本及影响并获用户明确批准，不能只说明覆盖代价后自行删除。
5. 用户已明确选择新版的本机 60 秒总预算硬截止。
   - 旧项目“仅告警”和新工具“本机硬截止”是不同产品行为；用户已明确批准改变前者。本机快速与完整验证均包含准备、缓存选择和执行，到期终止本次进程树、停止后续检查并失败；不新增单测试 3 秒限制。
   - 云端、拉取请求与持续集成保持工具原策略，不能以这些场景的告警结果替代本机硬截止验收。
6. 生产能力与验证证据分开。
   - 去掉重复 JIT 命令不改变生产编译合同；没有执行真正编译就不声称已证明它。
   - 私有快照缺失时只能跳过条件复算，不能转绿或造夹具补数据。

预算失败语义已收敛，完整开始开发门禁已展示并获确认。用户把原 16×4 并发修正为 4×4 或 8×2，本次按最小改动选 4×4：只把外并发降到 4，既有工作树检查内并发 4 保留，不给所有检查新增内并发。线程与业务子进程仍须另行核算，不声称所有进程总数不超过 16。具体检查归属与普通原生库兼容性仍需最小运行证据，不预先声称全部可保护。

用户进一步要求按各仓库检查项及其资源消耗定制并发。上述 4×4 仅作为量化本次初始值；依据已有耗时与资源证据在精确清单中说明轻量内存与重浏览器、数据库、环境准备检查的安排，不额外建立调度框架或大型基准测试。
