# 01 共享根目录 Python 环境

- 状态：ready-for-agent
- 前置票据：无

## 用户结果

开发者只需在主仓库根目录安装一次约 1.4 GB 的 Python（脚本语言）环境；随后初始化根目录 `.worktrees/` 中的任意工作树，即可通过目录链接运行完整验证，不再重复下载或复制依赖。

## 实现范围

- 将工作树约定从 `.claude/worktrees/` 统一为根目录 `.worktrees/`。
- 更新 `scripts/setup-worktree.ps1`：
  - 主仓库继续创建和更新根目录 `.venv`；
  - 工作树只创建指向主仓库根目录 `.venv` 的目录链接；
  - 共享环境缺失或依赖清单不一致时明确停止并给出恢复位置。
- 更新现有用户入口测试和必要说明。

## 验收标准

- [ ] 新检出的主仓库可通过 `scripts/setup-worktree.ps1` 创建并准备根目录 `.venv`。
- [ ] 新工作树位于仓库根目录 `.worktrees/`。
- [ ] 新工作树运行同一脚本后，`.venv` 是指向主仓库根目录环境的目录链接。
- [ ] 工作树不会执行 `pip install`，也不会创建独立大型虚拟环境。
- [ ] 共享环境不存在时，脚本停止并提示在主仓库根目录初始化。
- [ ] 依赖清单与主仓库不一致时，脚本停止且不修改共享环境。
- [ ] Build and Verify（构建与验证）通过共享链接完成真实主流程。

- [ ] 同一检查在最小实现后通过。
